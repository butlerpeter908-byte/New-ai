# 🚀 Pro AI - Advanced Multimodal Assistant

Pro AI is a high-performance, professional-grade AI assistant built with a focus on speed, privacy, and seamless voice interaction. It leverages state-of-the-art models to provide accurate text and voice responses.

## ✨ Key Features

* **🎙️ Smart Voice Interaction:** Uses **OpenAI Whisper V3** for high-accuracy speech-to-text transcription.
* **🧠 Advanced Reasoning:** Powered by **Meta Llama 3.3 (70B)** for intelligent, context-aware conversations.
* **🔊 Natural Speech:** Integrated with **gTTS** for clear and professional voice responses.
* **🕒 Context Awareness:** Real-time updates for **Time, Date, and Weather** (provided only upon user request).
* **🔒 Privacy First:** No data storage. Conversations are session-based and strictly private.
* **🎨 Clean UI:** A custom, minimalist Dark Mode interface with a persistent floating mic and hidden branding for a premium feel.

## 🛠️ Tech Stack

- **Framework:** Streamlit
- **LLM:** Groq (Llama 3.3 70B Versatile)
- **STT:** Whisper-Large-V3
- **TTS:** Google Text-to-Speech (gTTS)
- **Timezone Management:** Pytz
